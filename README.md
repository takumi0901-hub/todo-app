# ToDo アプリケーション (ToDo App)

ブラウザで手軽に使える、モダンで高機能な ToDo リスト Web アプリケーションです。  
Node.js などの外部環境や事前インストールの必要がなく、ダブルクリックするだけですぐに使えます。

---

## 🚀 起動方法

### 方法 1: `start.bat` をダブルクリック（おすすめ）
フォルダ内にある `start.bat` をダブルクリックするだけで、自動的にお使いの標準ブラウザでアプリが起動します。

### 方法 2: `index.html` を直接開く
`index.html` を Chrome、Edge、Firefox などのブラウザにドラッグ＆ドロップするか、ダブルクリックして開いてください。

---

## ✨ 主な機能

- **タスクの追加・編集・削除**:
  - タスク内容、優先度（高・中・低）、カテゴリ、期限日（カレンダー選択）を設定可能
  - ペンアイコンから既存タスクの内容や期限をいつでも編集可能
- **進捗の可視化**:
  - 全タスクに対する完了タスクの割合（％）とグラデーション付きプログレスバーをリアルタイム表示
- **ステータス管理**:
  - ワンクリックで完了 / 未完了を切り替え
  - 完了済みタスクには取り消し線が表示されます
- **絞り込み & ソート**:
  - ステータスフィルター（すべて / 未完了 / 完了済み）
  - カテゴリフィルター（仕事 / プライベート / 買い物 / 勉強 / 一般）
  - リアルタイムキーワード検索
  - 並び替え（作成日順 / 期限日順 / 優先度順）
- **期限アラート**:
  - 今日が期限のタスクや、期限を過ぎたタスク（超過日数）を色分けして視覚的に警告表示
- **自動保存（LocalStorage）**:
  - 入力したタスクデータやダークモード設定はブラウザに自動保存されるため、ページをリロードしたりブラウザを閉じても消えません
- **データのバックアップ・復元（エクスポート / インポート）**:
  - 右上のクラウドアイコンから、タスクデータを JSON ファイルとしてダウンロード・復元可能
- **ダークモード対応**:
  - 右上の月/太陽アイコンで、ダークテーマとライトテーマを瞬時に切り替え可能
